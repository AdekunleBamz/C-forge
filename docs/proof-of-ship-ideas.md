# Proof of Ship MiniPay App Ideas

Six practical MiniPay apps that fit the campaign brief and can produce real Celo mainnet activity:

1. C-forge CFRG mint pass
   - Users mint `1000 CFRG` with `0.002 CELO` on web or `0.0002` stablecoin in MiniPay.
   - Good leaderboard fit: simple onboarding, direct transaction count, stablecoin MiniPay flow, public SDK for reuse.

2. Text-to-NFT agent mint studio
   - User enters a prompt, an AI agent generates metadata and artwork, then mints the NFT on Celo.
   - Agent booster path: register the creation agent with ERC-8004 and charge optional x402 pay-per-generation fees.

3. Local merchant loyalty stamps
   - Customers scan a QR code and claim loyalty points or badges after a MiniPay stablecoin purchase.
   - Good leaderboard fit: unique users, repeat transactions, local utility.

4. Pay-per-use AI tools for MiniPay
   - Tiny x402 payments unlock translation, flyer generation, product descriptions, or image generation.
   - Good leaderboard fit: agent integration, stablecoin payments, usage-driven transactions.

5. Community task bounty board
   - Small Celo stablecoin bounties for local tasks, content, referrals, or event support.
   - Good leaderboard fit: B2C onboarding and real settlement.

6. Proof-of-attendance rewards for IRL events
   - Attendees claim a MiniPay reward or badge after location/event verification.
   - Good leaderboard fit: growth loops, unique active wallets, easy community demos.

For the AI agent prize pool, the strongest extension is idea 2: an ERC-8004 registered agent that accepts a text description, creates NFT metadata/art, and exposes an agent wallet with onchain transactions.
